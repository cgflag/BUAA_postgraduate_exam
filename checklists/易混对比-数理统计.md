## 1. 估计优良性

| 概念 | 一句话 | 典型误区 | 快速自检问句 |
|------|--------|----------|--------------|
| 无偏 | $E\hat\theta=\theta$ | 无偏就最优 | 期望是否等于参数？ |
| 有效 | 方差达到 CRLB | 有效=UMVUE | 方差是否贴下限？ |
| UMVUE | 无偏里方差一致最小 | UMVUE 必达 CRLB | 是否基于完全充分的无偏？ |
| 相合 | 样本大 → 依概率到真值 | 有限样本也保证 | 谈的是极限还是有限 n？ |
| MSE 最小 | 方差+偏差² 综合小 | 一定无偏 | 是否允许有偏换方差？ |
| MLE | 使似然最大 | MLE 一定无偏 | 用了不变性没有？ |

**必背逻辑链**

```text
达 CRLB 的无偏估计 ⇒ 有效 ⇒ 一定是 UMVUE
UMVUE ⇏ 一定达 CRLB
```

## 3. 检验相关

| 概念 | 一句话 | 别和谁混 |
|------|--------|----------|
| 水平 $\alpha$ | $H_0$ 真时拒真的上界 | 不是势 |
| 势 | 参数为 $\theta$ 时拒绝的概率 | 不是 p 值本身 |
| LRT | 用似然比造检验 | 不是永远 UMP |
| UMPT | 一致最优势 | 要条件，不是每题都有 |
| 无偏检验 | 备择势 ≥ 水平相关要求 | 不是「估计无偏」 |

## 4. 正态向量

| 说法 | 对/错 | 修正 |
|------|-------|------|
| 不相关 ⇒ 独立 | 一般错 | 正态（联合正态）等条件下才有 |
| $\mathrm{Cov}=0$ ⇔ 不相关 | 对（定义向） | 注意题目问的是充要还是充分 |
| 实矩阵特征值必实 | 错（矩阵课也考） | 对称/Hermitian 才保证 |
