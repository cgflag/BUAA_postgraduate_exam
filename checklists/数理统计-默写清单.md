## A. 参数估计

- [ ] 矩估计：原理一句话 + 标准步骤
- [ ] MLE：似然 → 对数 → 求导 → 验证极值（含边界情况提醒）
- [ ] 充分统计量：定义；最小充分（直觉即可）
- [ ] 指数族形式：能认出 $c(\theta)h(x)\exp(w(\theta)T(x))$ 并指出 $T$
- [ ] UMVUE 三步：完全充分 → 无偏（或 RB）→ Lehmann-Scheffé
- [ ] Rao-Blackwell：在说什么（用条件期望改进）
- [ ] CRLB 公式骨架 + 「方差=CRLB ⇒ 有效」
- [ ] **关键**：UMVUE 是否一定达到 CRLB？（答：不一定）
- [ ] MSE = 方差 + 偏差²；无偏时 MSE=方差
- [ ] 相合性：大样本直觉；线性变换下是否保持

## B. 多元正态

- [ ] $X\sim N(\mu,\Sigma)$，$Y=AX$ ⇒ 均值、协方差
- [ ] 正态下：不相关 ⇔ 独立（条件是什么）
- [ ] 用 $\mathrm{Cov}=0$ 证明独立的典型套路
