## Day 1 · 题型地图 + UMVUE（3–4h）

- [ ] 打开 `心得` 开头「题型」，纸上列出判断 / 填空 / 大题各有什么（20min）
- [ ] 对照 `题型步骤` 里「题型 A」，和心得 UMVUE 三步对齐，手抄一份自己的步骤名（50min）
- [ ] 合书默写 UMVUE +「是否有效」判定；对默写清单（40min）
- [ ] 复盘前几道判断：先做后看；旁注缺条件还是单向搞反（30min）
- [ ] 写不出 UMVUE 三步就重做本日前两项

---

## Day 2 · 多元正态 + 再练估计（3–5h）

- [ ] 回看昨天卡壳处（15min）
- [ ] `题型步骤` 题型 D + 心得多元正态；自造一个 2 维小例子算一遍（50min）
- [ ] 交错：按题型 A 空跑一道估计（可用往年/模拟骨架）（50min）
- [ ] 易混表：无偏 / 有效 / 相合 / UMVUE（40min）
- [ ] 合书：写出 $Y=AX$ 的均值协方差；能说清「UMVUE 未必达 CRLB」

---

## Day 3 · 似然比（3–5h）

- [ ] 回看（15min）
- [ ] `题型步骤` 题型 B + 心得 LRT；在纸上画出你用的那套 λ（注意和课堂一致）（70min）
- [ ] 势函数：先有拒绝域再写 $g(\theta)$；读易混短注里「势」那一小节（40min）
- [ ] 默写清单检验条目（30min）
- [ ] 合书能讲完 LRT 各步，并说清分子分母谁是谁

## Day 4 · UMPT + 填空（3–4h）

- [ ] 回看（15min）

- [ ] 只补断掉的那几步（心得或题型步骤）（40min）
