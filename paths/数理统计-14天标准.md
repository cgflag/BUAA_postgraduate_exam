## 第 1 周：按题型建步骤

### Day 1 · 地图

- [ ] 读本路径说明 + `题型步骤` 开头「对号入座」（15min）
- [ ] `心得` 题型总览 → 纸上画试卷结构（20min）
- [ ] 多叉树里统计量 / 充分统计量，摘十个词各一句话（50min）
- [ ] 笔记扫标题，标以后要回看的节（30min）
- [ ] 合书：充分统计量是什么、干什么用

### Day 2 · MLE / 矩估计

- [ ] 多叉树：矩估计、MLE 步骤各手写一遍（60min）
- [ ] 心得里估计相关例：盯步骤不盯数字（40min）
- [ ] 合书默写 MLE；能解释均匀分布为何常在边界取到（对照题型步骤里均匀那句 / 易混短注）

### Day 3 · UMVUE（题型 A）

- [ ] 心得 UMVUE 三步 + RB / LS（50min）
- [ ] `题型步骤` 题型 A 全文，对照自己的步骤名是否少步（40min）
- [ ] 易混短注：充分 / 完备 / UMVUE；CRLB 单向（20min）
- [ ] 练一遍 $\mu^2$ 移项那种填空思路（复盘里有）（20min）
- [ ] 合书默写步骤名；口述「UMVUE 不一定有效」

### Day 4 · 多元正态（题型 D）

- [ ] 题型步骤 D + 心得，自造小例子（60min）
- [ ] 独立：先 Cov 再引用联合正态特权（40min）
- [ ] 往年记录里相关条目对照（30min）
- [ ] 合书写出 $Y=AX$ 公式

### Day 5 · 似然比（题型 B）

- [ ] 题型步骤 B + 心得，画流程图；确认 λ 与课堂一致（70min）
- [ ] 势与无偏检验；易混短注「势」小节（40min）
- [ ] 模拟拆解标检验考点（25min）
- [ ] 合书讲完各步

### Day 6 · UMPT（题型 C）

- [ ] 心得 UMPT / 指数族（50min）
- [ ] 自己画一张小表：LRT 何时用、UMP 何时用（30min）
- [ ] 复盘检验向判断三道（40min）
- [ ] 合书：UMP 入口至少三条

### Day 7 · 填空 + 周测

- [ ] 题型 E/F：贝叶斯后验期望、MSE、符号秩和（50min）
- [ ] 翻牌自测：先答后展开（30min）
- [ ] 默写清单本周相关项；半会的抄到纸上（40min）
- [ ] 休息，别开新章

## 第 2 周：交错、假考、复盘

### Day 8 · 估计 + 正态交错

- [ ] 合书空跑两道估计步骤（50min）
- [ ] 多元正态一道 + 易混表（50min）
- [ ] 改：每题标断在第几步（40min）

### Day 9 · 检验交错

- [ ] LRT 全流程空跑（60min）
- [ ] 势 / 无偏只默写判定句（30min）
- [ ] 模拟 + 往年检验向（50min）

### Day 10 · 假考 #1

- [ ] 开考前翻 `题型步骤`「对号入座」（10min）
- [ ] 计时合书；大题先写步骤名（90min）
- [ ] 改卷：大题断步；判断旁注原因（40min）
- [ ] 当天不学新内容

### Day 11 · 补洞

- [ ] 只打开断掉的题型对应章节（心得 / 题型步骤 / 易混短注）
- [ ] 每类错误再做一道最小变式
- [ ] 更新默写清单

### Day 12 · 复盘

- [ ] 复盘先做后看；每题写一句考点（长一点没关系）
- [ ] 对照 [`meta/考纲漂移日志.md`](../meta/考纲漂移日志.md) 数理段

### Day 13 · 假考 #2

- [ ] 缩短版假考（60–90min）
- [ ] 判断专项：复盘 + 易混表
- [ ] 开始写一页纸草稿

### Day 14 · 收束

- [ ] 定稿一页纸：UMVUE、LRT、$Y=AX$、CRLB、易混两点、假考最大坑
- [ ] 半会项能放弃就放弃
- [ ] 别开新章
